# 자동 새 창 차단

사이트가 자동으로 여는 팝업을 차단하는 Chrome Manifest V3 확장 프로그램입니다. 설치하면 크롬의 팝업 설정을 차단으로 설정합니다. 외부 라이브러리, 서버, API 키가 필요하지 않으며 방문 기록을 수집하지 않습니다.

## 크롬에 설치

1. [설치용 ZIP 다운로드](https://github.com/ryujuhwa/chrome-feautures/raw/refs/heads/main/downloads/chrome-popup-blocker.zip)를 눌러 다운로드합니다.
2. 윈도우 파일 탐색기의 **다운로드**에서 `chrome-popup-blocker.zip`을 우클릭하고 **모두 추출 → 추출**을 누릅니다. 압축을 푼 폴더 안의 `chrome-popup-blocker/extension`에 `manifest.json`이 있는지 확인합니다.
3. 크롬 주소창에서 `chrome://extensions`를 엽니다.
4. **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `extension` 폴더를 선택합니다.
6. 도구 모음에서 확장 프로그램을 고정하면 차단 상태를 확인하고 설정을 해제할 수 있습니다.

차단 해제는 팝업을 강제 허용하지 않고, 이 확장 프로그램이 설정한 규칙을 제거하여 기존 크롬 설정으로 돌아갑니다. 기존 설정도 차단이면 크롬 설정은 계속 차단으로 표시되며, 확장 프로그램 자체는 꺼짐으로 표시됩니다. 제거 시에도 크롬이 확장 프로그램의 설정을 해제합니다.

## 차단 범위

- 웹사이트가 사용자 동작 없이 여는 자동 팝업과 새 창을 크롬의 기본 팝업 차단기로 차단합니다.
- 직접 클릭한 링크나 로그인·결제 창은 크롬의 사용자 동작 판정에 따라 열릴 수 있습니다. 클릭 직후 발생하는 광고 팝업도 허용될 수 있습니다.
- 사이트별 허용 규칙, 관리 정책, 다른 확장 프로그램의 설정이 우선할 수 있습니다. 팝업 화면의 상태는 대표 HTTPS 주소에 대한 유효 설정이며 모든 사이트의 상태를 보장하지 않습니다.
- 다른 확장 프로그램, 악성 프로그램, 운영체제가 직접 여는 창은 대상이 아닙니다.
- 시크릿 모드는 별도로 제어하지 않습니다.

## 개발 및 검증

Node.js 24와 Chromium을 사용합니다. 의존성 설치나 빌드가 필요하지 않습니다.

```sh
node --test tests/*.test.js
```

실제 브라우저 검증은 `tests/browser_smoke.py`로 실행합니다. Python Playwright와 Chromium이 필요합니다.

```sh
python tests/browser_smoke.py
```

확장 프로그램 수정 후 `chrome://extensions`에서 새로고침합니다. 자동 팝업 차단, 직접 클릭한 링크 허용, 설정 해제 후 기존 설정 복원을 확인하세요.

현재 클라우드 Chromium은 관리 정책으로 압축 해제 확장 프로그램 로딩을 금지하여 실제 브라우저 테스트를 실행할 수 없습니다. 단위 테스트는 실행할 수 있으며, 브라우저 테스트는 해당 정책이 없는 개발용 Chromium에서 실행하세요.
